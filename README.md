# Tina Dahl — Portfolio

Portfolio website for hospitality photography and filmmaking.

Built as a lightweight, image-led portfolio for showcasing photography and short-form film projects for hotels and hospitality brands.

## Tech

- Astro
- Vanilla CSS
- JavaScript
- Self-hosted custom typeface
- Netlify

## Structure

- Selected projects
- Individual project case studies
- Photography archive
- About

Project and photography content is managed through local files.

## Development

Install dependencies:

```bash

npm install

```

Start the local development server:

```bash

npm run dev

```

Create a production build:

```bash

npm run build

```

## Deployment

The site is deployed via Netlify with continuous deployment from the `main` branch.
